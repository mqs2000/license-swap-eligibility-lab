# License Swap Eligibility Agent — IBM watsonx Orchestrate Lab

A hands-on lab for **IBM watsonx Orchestrate (WXO)**.

## What you'll build

An AI agent that guides users through checking whether their foreign driving license qualifies for a UAE license swap — without needing to take a driving test. The agent collects the license, reads it automatically, checks the nationality against an eligibility list, and returns a personalised response.

## Estimated time

~30 minutes
